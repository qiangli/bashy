# `custom/` — External-Binary & Custom Command Adapters

Inventory of every command class under `custom/` (Sprint #677, Story #608 / `21d630caff46`, parent `ee056056de3e`).

All converted commands follow the uniform folder-adapter contract:
- `bashy/custom/<cmd>/<cmd>.bsh` — 14-line Bash# adapter compiling and caching the standalone binary under `GOWORK=off CGO_ENABLED=0` and exec'ing with argv/stdio/env/exit status unchanged.
- `bashy/custom/<cmd>/main.go` — minimal standalone Go entrypoint calling the existing constructor/shim.
- `bashy/custom/<cmd>/<cmd>_test.go` — fast unit test verifying behavior and asserting via `GOWORK=off go list -deps .` that no other command package is linked.
- `internal/agentos/` routes each converted verb through `runCommandAdapter("custom", entry, invokedAs, args)`.

### Related Non-Custom Note
- `vuln` (`internal/agentos/vuln.go`) is a composite Go orchestrator over `govulncheck`, `osv-scanner`, and `grype` (not a single external-binary shim) and remains in `internal/agentos/` while each individual scanner (`govulncheck`, `osv-scanner`, `grype`) is converted under `custom/`.
