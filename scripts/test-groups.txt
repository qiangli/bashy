# Test groups: every package of `go list ./...` (union over linux, darwin and
# windows) belongs to exactly ONE group. `scripts/test-groups.sh --check`
# enforces it fail-closed. Spec: docs/todo/45786df1114b-*.md "Test groups".
#
# Format: <group> <package> [<Test>|<Test>...]
#   Without a test list the line is the package's home: the whole package runs
#   in that group. A package must have exactly one home line.
#   With a test list (e2e only) those top-level tests run in e2e with -run and
#   the home group runs the package with the matching -skip.
#
# core/agentos/frontend/tooling/examples reuse Go's content-keyed test cache;
# e2e always runs fresh (-count=1).
