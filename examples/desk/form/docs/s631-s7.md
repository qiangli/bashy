(agent-defined forms, human-filled on the loopback page, answers back as

## Fork-or-build decision (re-verified 2026-11-13)

## Shapeable badge checklist

- Registered as a shaped web app (`register.sh` → `app add --type shaped`
  plus command and skill records); kind `web`, scope `principal`.
- Declares checks the verifier runs (`contract.bsh` effect cap,
  `checks/go.bsh` builds the module and runs its tests). A check can fail:
  a deliberately broken candidate verifies `pass: false` and approval
  leaves it unactivated (negative probe below).
- Activation is scoped per principal; undo and history work (demo below).
- Every web action has its `bashy shape` CLI equivalent (used throughout).

## Shaping demo (isolated home, product build from this repo)

Wish: add the words "shaped for me" to the form page footer.
One-line change to `server/main.go`; nothing else differs from base.

- Base revision: `9d7c3ca9ea13…`
- Candidate `803466bcc2b3a4e2`, revision `48d1a14faf40…`
- `shape show` / `shape diff`: exactly the footer line.
- `shape verify`: `pass: true` with verifier evidence.
- `shape preview`: preview URL issued; the candidate server page contains
  the marker (1 match) while the base server page does not (0 matches),
  served from isolated checkouts on loopback ports.
- `shape approve` for `device:alice`: alice active `48d1a14faf40…`,
  `device:bob` still on base `9d7c3ca9ea13…` — visible only to the
  requester.
- `shape undo` for `device:alice`: alice back to `9d7c3ca9ea13…`;
  history lists the activate and undo entries with passing verdicts.
- Negative probe: candidate `f45345a14d82ed76` (broken build) verifies
  `pass: false` ("not every required check passed") and `shape approve`
  leaves it unactivated.

Reproduce (isolated, nothing touches the host home):

```bash
./scripts/go-product.sh build -o /tmp/s7-bashy ./cmd/bashy
export BASHY_HOME=<empty-dir> BASHY_BIN=/tmp/s7-bashy GOWORK=off
bashy/examples/desk/form/register.sh form
bashy shape wish form "…" --from <workspace> --user device:alice --as <agent>
bashy shape verify form <candidate> --user device:alice --as <agent>
bashy shape preview form <candidate> --user device:alice --as <agent>
bashy shape approve form <candidate> --user device:alice --as <agent>
bashy shape undo form --user device:alice --as <agent>
```
