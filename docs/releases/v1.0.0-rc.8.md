# Bashy v1.0.0-rc.8

Development candidate for the bashy product pair. The release tag builds bashy,
outpost, bash, and sh from one pinned source graph.

## Cluster runtime

- The DKS control-plane runtime image is built FROM scratch by bashy from
  signed forks (k3s, runc, CNI plugins, metrics-server, tailscale, coredns),
  with no upstream-built image or base layer. `builds/k3s/README.md` maps each
  compiled-out path to its regression symptom.
- outpost reconciles a persisted etcd peer after the bridge is recreated,
  reports pod addresses on a shared control-plane bridge, exports hosted-plane
  metrics to the active OpenTelemetry collector, and pulls from a loopback
  registry (the host's own zot) without TLS. Remote registries keep TLS
  verification.

## Models

- Kimi (Moonshot) models and their agent bindings are available again, with
  genie model ids.
- A cgo-off engines build serves local GGUF models: the managed Ollama server
  registers the pure-Go model tokenizers and selects the pure-Go engine unless
  `OLLAMA_NEW_ENGINE` is set.

## Fixes

- Windows: `locale -a` re-checks a host locale refused under concurrent probes
  one at a time (a WSL-backed provider could list none).
- Dependency updates with available vulnerability fixes; the release
  vulnerability scan covers the release tag sets of the bashy executable.
