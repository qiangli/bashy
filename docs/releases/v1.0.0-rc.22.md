# Bashy v1.0.0-rc.22

Development candidate for the bashy product pair. The release tag builds bashy,
outpost, bash, and sh from one pinned source graph. rc.22 ships the outpost
fleet-upgrade ordering fix: no host running an `-rc.N-dev` build accepted a
promoted release before it.

## Fleet upgrades

- outpost's never-downgrade guard now accepts a promoted `v1.0.0-rc.M` over a
  running `v1.0.0-rc.N-dev` build when `M > N`. Before, it compared the
  identifiers `N-dev` and `M` as semver, which ranks any text identifier above
  any number, so every promotion was declined ("target semver not strictly
  newer"). When the running build is a prerelease, the `-dev`-stripped base
  decides: a strictly newer base is accepted; an equal or older one is declined.
- Hosts still on an older outpost must move once onto this build
  (`outpost upgrade --from <rc.22-dev asset URL> --sha256 <hex>`); after that,
  promotions apply automatically.

## Peer storage

- outpost serves a stable local storage endpoint (127.0.0.1:31890) that routes
  each peer's S3 service by host name or path-style bucket, LAN first, then
  mesh; self storage routes without the mesh.

## Fixes

- outpost pin moves to the current outpost main.
