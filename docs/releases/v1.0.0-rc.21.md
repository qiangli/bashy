# Bashy v1.0.0-rc.21

Development candidate for the bashy product pair. The release tag builds bashy,
outpost, bash, and sh from one pinned source graph. rc.21 carries the loom
fixes satellites need and the fresh-host Matrix chat repair that rc.20 missed.

## Loom (private forge)

- When started as root on Linux (a satellite's local outpost), loom runs Gitea
  as an unprivileged system account instead of refusing to start, and makes
  every ancestor of its data directory traversable for that account.
- Object storage on a peer's S3 (seaweedfs) with a bucket-routed peer address
  and one S3 identity.
- Read replicas: `loom replica add/list/rm` (push mirrors), replica-aware clone
  and remote refresh, user-owned repos replicated and synced on add, mirrors to
  private-address replicas without hand-editing `app.ini`.
- Windows: loom provisions Git and the `bash` name Gitea's hooks need, and
  serializes toolchain installs.

## Collaboration tools

- `matrix-chat` setup enables the homeserver and shim services on a fresh host
  before restarting them.

## Fixes

- binmgr tree-cache fixes.
- Sibling pins move to the current yoke head.
