# bashy v0.24.9

Pre-1.0 patch release. Team collaboration under GitHub's three team shapes —
an org team with push for all, public open source with one owner and PR
contributors, and a mix — with GitHub's answer the only input.

## Fixed

- **A fork-layout checkout joins the team's session.** `gh repo fork --clone`
  leaves `origin` = your fork and `upstream` = the team's repo; the session
  key read `origin` only, so a PR contributor opened a private session on
  their own fork instead of joining the team's. The key now comes from
  `upstream` when it exists, else `origin`; `sprint session status` says
  which remote it came from when it is not `origin`.
- **A GitHub-derived seat follows GitHub.** Once a checkout had joined, its
  seat was frozen: a contributor granted push later stayed `observer`; a
  removed collaborator kept a `contributor` view. Every verb now re-derives a
  `contributor`/`observer` seat through join-by-repo (owner and hand-shared
  members pay nothing), `sprint session status` prints
  `role: observer  (GitHub, as of <ts>)`, and a revoked grant is said by
  name — never a silent private session.
- Two `supervisord` tests left a file open and failed only in Windows
  TempDir cleanup.

## Changed

- **A sprint carries the three handles every entity has.** Beside its seq a
  sprint now has a uuid (the identity across hosts) and a slug; cards that
  predate this get both on demand, deterministically, and the next write
  persists them. `bashy sprint show` prints
  `ref: sprint:<seq> · <uuid> · <slug>` and
  `path: sprint:<user>/<host>/<seq>` (the ancestral path — a seq is unique
  only within its parent), accepts any of them, and `bashy define
  sprint:<uuid|slug|path>` resolves to the canonical `sprint:<seq>`. A path
  under another user/host is named as such and points at the uuid.
- `ref.SplitScope` splits a scoped ref on the LAST `/`: a scope is the chain
  of parents at any depth; the local part is always one handle.
- Live seats on both hosts of a session (ConPTY backend on Windows); every
  seat joins the session; the relay keeps a seat's mail (yoke `668d34d`).
- The bashy app: Settings › Cloud (cards when paired, one-click Pair when
  not), Neighborhood (same-LAN hosts via mesh + mDNS), a peer's desktop over
  the mesh at `/desktop/<peer>`.
- `bashy dag`: a DAG-backed `supervisord` (PID 1 for a static Linux scratch
  image); `fmtcheck` runs without an Effects cap.
- Rust through `bashy dag` on Windows: linker response files, export lists
  and argument quoting adapted for the Zig link step.
