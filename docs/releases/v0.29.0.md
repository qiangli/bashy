# Bashy v0.29.0

Pre-1.0 minor release following v0.28.0. Classic Bash remains the default
language mode. This release is a clean-baseline measurement release: one
engine fix, and every conformance number re-measured on one reference
revision (`sprint-269`) on Linux, macOS and Windows.

## Fix

- Go-source programs that use a package map (`--go-import-base`) can import
  the standard library again. v0.28.0 applied the program's internal-package
  rule to the standard library's own dependencies, so `import "fmt"` failed
  with `use of internal package internal/poll not allowed`.

The Go corpus is the one open area: 257 of the 380 failing roots are
reviewed exclusions an interpreter cannot reproduce (compiler diagnostics,
assembly checks, cgo, `unsafe` reinterpretation); the other 123 are open work,
published by ID with their first causes in `bashsharp/docs/go-corpus-state-2026-09-24.md`.
Every figure and its run is in `bashsharp/docs/claims.md`.

## Evidence and scope

The candidate is gated by the serial GNU Bash 5.3 fixture suite, three-OS
`test` CI, tag conformance and native airgap images, published-byte QA on
macOS, Linux and Windows, and all six Bash# tour runner legs. Exact candidate
and sibling commits and receipts are recorded in the Sprint 269 release
evidence.

No POSIX certification award or mark is claimed.
