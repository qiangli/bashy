# Bashy v0.31.0

Pre-1.0 minor release following v0.30.0. Classic Bash remains the default
language mode. This release carries a large round of Bash# interpreted-Go
engine work, fixes a v0.30.0 regression that stopped the builtin genie
agent from running, and improves live steering of agent CLIs.

## Engine (Bash# interpreted Go)

- About 140 interpreter changes from the Go 1.27 compiler-package work
  (Sprints 281 and 319). Programs that call into native dependencies keep
  more of Go's typing across the boundary: dependency variables keep their
  declared and interface types across reassignment and short declarations,
  typed range-function yields, unsafe pointers in typed aggregates, imported
  collection field reads, and shared-cell reads that always take one
  consistent snapshot.
- **Fixed:** after a native call rewrote a slice in place (`sort.Strings`,
  `sort.Ints`), ranging over that slice failed with
  `BASHPP-EEXPR-OPERAND: ... is not a scalar`. The type tag a callback result
  now carries stays on the top-level result and no longer leaks into
  collection elements. The regression shipped in v0.30.0 and stopped
  `bashy genie solve` in every task.

## Agents

- `bashy genie`: the builtin genie no longer aborts long tasks on a
  25-invocation hook cap, resumes its session once when a task ends without a
  diff, and leaves editor backup files (`*.bak`, `*~`, `*.orig`, `*.rej`) out
  of its patch.
- `bashy chat steer` interrupts first for CLIs that hold typed input until
  the turn ends, and sends a second Enter after a steer line; headless agent
  terminals answer the secondary device-attributes query.

## Fixes

- Text fences run by the podman processor start bashy's podman machine when
  it is stopped (the same start `@contain` uses).
- `bashy podman` on Windows keeps System32 on PATH, so the machine's
  `wsl.exe` is found.

## Measured on this release

The candidate is gated by the serial GNU Bash 5.3 fixture suite (86), the
licensed POSIX shell arm (493 test purposes), three-OS `test` CI, tag
conformance and native airgap images, published-byte QA on macOS, Linux and
Windows, and all six Bash# tour runner legs. Exact candidate and sibling
commits, counts and receipts are in the Sprint 322 release evidence.

No POSIX certification award or mark is claimed.
