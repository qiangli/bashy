# bashy v0.24.2

Pre-1.0 patch release.

## Fixed

- **`bashy check --bashsharp` null safety on a complete script.** The
  checker only fired on a file that was nothing but typed declarations; a
  `func deref(p *int)` inside an ordinary shell program passed silently.
  It now walks typed declarations inside a complete Bash# script
  (`BASHPP-ENULL-DEREF`, exit 2) — the Bash# tour's `06-sharp/05-null-safety`
  case proves it.
- **`bashy upgrade install` replaces the running bashy on Windows.** The
  install renamed the new file over the destination, which Windows refuses
  for a running image ("Access is denied"); it now parks the running image
  at `<bashy>.old` and puts the new one in its place.

## Changed

- **Work items classify with any word.** `bashy todo add --kind <word>`
  (bug, feature, enhancement, doc, task, chore, spike, test, refactor,
  requirement, question are the common ones; any other word is accepted)
  and `--label <word>` on `todo add`/`edit`; `todo list --kind/--label`
  filters; `todo kinds` / `todo labels` list the words in use;
  `sprint show` prints a kinds breakdown.
