# Bashy v1.0.0-rc.4

Development candidate for the bashy product pair. The release tag builds bashy,
outpost, bash, and sh from one pinned source graph.

## Release and runtime checks

- Promotion requires a passing tier verdict for the candidate and signed
  release assets for each supported operating system. The regular test workflow
  also runs nightly.
- Release builds include the pinned OpenTelemetry assets. The release workflow
  reports the current Go dependency license inventory while the remaining
  reviewed license work is tracked separately.
- The scratch supervisor smoke check is bounded to its one-shot unit.

## Agent and model tooling

- Model quota commands show usage observations and forecasts, with account
  labels and controls for probing current quotas.
- Managed local Ollama uses its own engine wiring. Product builds embed the
  signed runner for each supported operating system.

## Fixes

- Formatted help re-executes the running bashy binary, so it does not depend on
  another bashy found through PATH.
- Release CI fixtures and Windows test portability were corrected; the app
  service end-to-end test now avoids a port-helper collision.
