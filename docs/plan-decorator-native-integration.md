interpreter and compiled continuations. Copy mutable arguments, results and
status across each Next boundary; carry the supplied context into the engine.

missing trusted-native rung so calls fail closed; certification loads no rules.
Guard caps use the complete atlas effect vocabulary and deny unknown effects.

Verify actual spans, command denial and its audit record, retry counts, nested
context isolation, source shadowing, invalid configuration and certification.
