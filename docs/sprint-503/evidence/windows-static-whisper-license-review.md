This supports the default tag's `c28e9555bb8800c53449f42a465ad9a5676fce88` source pin for the release zips, but the reviewed binary artifacts contain no archive-member link map or included notice bundle. The MinGW runtime notice also contains an unresolved Cephes math permission `FIXME`; no Cephes compile unit was found in these binaries, which does not rule out embedded objects or inline code.
