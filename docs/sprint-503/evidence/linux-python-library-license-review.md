The observed build loaded host-provided `.so` files dynamically; its inventoried Python prefix did not copy those Ubuntu libraries. The installed Python license file has SHA-256 `3b2f81fe21d181c499c59a256c8e1968455d6689d269aa85373bfb6af41da3bf` on both targets. [Python's license terms](https://docs.python.org/3.12/license.html) require the applicable PSF notice in a redistributed Python distribution and a change summary for a derivative. For an LGPL-linked distributed program, [LGPL 2.1 section 6](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.dbk) calls for a library-use notice and LGPL license text, with a suitable shared-library mechanism or another compliant route. Copying any Ubuntu library into a product would require reviewing its own distribution terms and notices. OpenSSL's [license terms](https://openssl-library.org/source/license/index.html) and [Apache-2.0 section 4](https://www.apache.org/licenses/LICENSE-2.0) matter if OpenSSL is redistributed.

Both replacement receipts show 3,358 installed files, 73 extensions including `_bz2` and `_lzma`, and successful zlib, bz2 and lzma import/round trips. Exact-byte rechecks passed under OS network denial. The earlier [run 40207782322](linux-python-source-40207782322/review.json) lacked those two codecs; its wrapper-presence result is superseded.

These receipts do not prove what a later product installer copies, whether an operator host has the same library versions, or whether static/embedded code introduces more notices. The observed build used host-provided dynamic libraries. Retain this exact notice set, verify operator-host library integrity, and review any libraries copied into the final installer before product admission. The pre-execution launcher is a local drift guard until an immutable signed interpreter pin is available. Keep S503.6 open.
