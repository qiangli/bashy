# S503.8 runner identity preflight

The `S503 runner identity preflight` workflow is a short identity check for the
six public GitHub-hosted targets: `ubuntu-24.04`, `ubuntu-24.04-arm`,
`macos-15-intel`, `macos-15`, `windows-2025`, and `windows-11-arm`. It runs on
pushes to `s503-contract-integration` when this workflow or this note changes,
and can also be started with `workflow_dispatch`.

Each job records its runner label, OS architecture from the kernel or Windows
runtime, process architecture, macOS translation state, native Go host
architecture, Node/Go/Bash versions, and commit SHA in a JSON artifact. An OS
or architecture mismatch, translated macOS process, or nonnative Go toolchain
fails that job. The six artifacts establish runner identity
and toolchain availability only; they are **not native transcription results**.
S503.8 currently has **0/6 full native passes**.

The later native gate should reuse these exact six labels and keep the same
identity JSON as per-target evidence, then add the candidate-linked build,
offline inference, fixture transcript, and timing checks. GitHub documents
standard public-repository runners as free and unlimited:
[GitHub-hosted runners](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).
