# S503.6 Whisper executable notice bundle

Story #2742, Story-ID `74ed924ba244`. This is a reproducible notice **candidate** for the six native Whisper executable targets. It does not admit a product artifact or authorize distribution. The generator runs offline after the pinned source build and places `THIRD_PARTY_NOTICES.txt`, exact upstream license files, and `NOTICE_MANIFEST.json` beside the binary in the build evidence artifact.

## Source and evidence binding

`examples/transcribe/dependencies/notices/source-pins.json` records each upstream URL and notice SHA-256. The generator verifies the 9,626,464-byte [Whisper v1.9.5 source archive](https://github.com/ggml-org/whisper.cpp/archive/refs/tags/v1.9.5.tar.gz) at SHA-256 `ff1a9053feb509ff9d7729703355541ae9690073a6b1c40eb692c962e0dc1720`, then compares its `LICENSE` byte for byte with the committed MIT notice. It verifies the build report and executable digest on every target. On Windows it also verifies the llvm-mingw zip pin, compiler path, complete linker archive name set, four nonarchive objects, raw linker map digest, and duplicated inventory. Optionally, `--review` binds those inputs to the retained [run 40210246732 review](sprint-503/evidence/windows-static-whisper-40210246732/review.json).

The retained Windows binaries produced identical notice text SHA-256 `aba6e4b5ac2a618e550a310c22eb55c11109a7a64f13f31ad3754a115a94f2eb`. Their manifest binds amd64 binary SHA-256 `27e0bb8c1e0d3b6d38ba06874e2c417e4e98aaff508fc2cc73ec4638b391d123` and map SHA-256 `492d869f01ce5a8afb23edffd51b3fe4a53626cfd16ee14ce910cd4f3019746e`; arm64 binary SHA-256 `47358db49ac9385e77f3b135a2b5cccb186cc565b81a0c5db278301bc9ea79de` and map SHA-256 `2639fd586fe652d6bcee3a2b1022ea05b4dfcfeeac445549bd29f953ddd318f3`. The prebuilt zip pins are recorded separately for each architecture in `source-pins.json`. A matching zip hash establishes asset identity, not the source lineage of each member in it.

## Applicable notices and open review

The linked `ggml`, `whisper`, and `common` archives derive from the verified [Whisper v1.9.5 source archive](https://github.com/ggml-org/whisper.cpp/archive/refs/tags/v1.9.5.tar.gz), whose root license is MIT. The object-to-source, file-level notice check is still open. The Windows linker maps also load LLVM `libc++`, `libunwind`, and compiler-rt objects. The bundle conservatively carries the pinned [libc++](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-22.1.8/libcxx/LICENSE.TXT), [libc++abi](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-22.1.8/libcxxabi/LICENSE.TXT), [libunwind](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-22.1.8/libunwind/LICENSE.TXT), and [compiler-rt](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-22.1.8/compiler-rt/LICENSE.TXT) license texts. LLVM describes its general terms as Apache-2.0 with LLVM exceptions in its [license](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-22.1.8/llvm/LICENSE.TXT). The llvm-mingw [assembly project license](https://raw.githubusercontent.com/mstorsjo/llvm-mingw/20260616/LICENSE.txt) covers scripts and wrappers; it does not supersede the linked component licenses.

The Windows linker maps load `libmingw32.a`, `libmingwex.a`, `libmsvcrt.a`, and `crt2.o`/`crtbegin.o`/`crtend.o` from llvm-mingw. The bundle carries pinned MinGW-w64 [general COPYING](https://raw.githubusercontent.com/mingw-w64/mingw-w64/c28e9555bb8800c53449f42a465ad9a5676fce88/COPYING), [static runtime notice](https://raw.githubusercontent.com/mingw-w64/mingw-w64/c28e9555bb8800c53449f42a465ad9a5676fce88/COPYING.MinGW-w64-runtime/COPYING.MinGW-w64-runtime.txt), and [public domain disclaimer](https://raw.githubusercontent.com/mingw-w64/mingw-w64/c28e9555bb8800c53449f42a465ad9a5676fce88/DISCLAIMER.PD). The runtime notice specifically instructs binary distributors to carry its notices. It includes a `FIXME` on Cephes math library permission. Before admission, map each loaded MinGW member to the pinned source file and its actual license, resolve that uncertainty, and establish source-to-prebuilt-zip provenance. The toolchain [tag](https://github.com/mstorsjo/llvm-mingw/tree/20260616) points to LLVM `llvmorg-22.1.8` and MinGW-w64 `c28e9555bb8800c53449f42a465ad9a5676fce88`; the retained receipt verifies the downloaded asset hash, not a signed source-to-asset build chain.

The Linux recipe uses `-static-libgcc -static-libstdc++`. The [GNU libstdc++ license](https://gcc.gnu.org/onlinedocs/libstdc%2B%2B/manual/license.html) states GPLv3 with the GCC Runtime Library Exception; this remains an explicit policy and legal review gate. Retain a Linux linker map and exact GCC runtime object inventory, then examine their source license and exception, or build a variant using host-provided dynamic libstdc++ and verify its imports and host package policy. On macOS, inventory linked system frameworks and their applicable host notices. These gates remain open in the generated manifests, including when the bundle builds successfully.

The generator is offline and performs no native build, install, model download, or inference. Run its focused checks with `python3 -m unittest discover -s examples/transcribe/dependencies -p test_build_whisper_notices.py`.
