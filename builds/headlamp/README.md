# headlamp — bashy verified server build

This declaration builds the official Headlamp `v0.45.0` tag (Apache-2.0,
commit `0e9fe810cb618964172f420666727c9a67fd6ebf`) as its embedded in-cluster
Go server for Linux and macOS, amd64 and arm64. Upstream's `make backend-embed`
is used: `npm ci`, Vite frontend build, `backend-embed-prepare`, then the Go
`embed` build. The four raw binaries are signed release assets.

The OCI job consumes the gated Linux binaries, creates a two-platform image on
upstream's digest-pinned Alpine 3.24.1 base, pushes
`ghcr.io/qiangli/headlamp:<bashy tag>`, signs the manifest digest keylessly,
verifies the workflow identity, and publishes the immutable reference in
`headlamp-image-digest.txt`. Only standard free runner labels are used.

## Privacy and egress

At this tag the frontend contains no analytics client. Backend telemetry is
OpenTelemetry and is opt-in: `-tracing-enabled` and `-metrics-enabled` both
default false. The image states both false, the shipped environment disables
the SDK/exporters, Helm and dynamic clusters, and no static or downloaded
plugins are included. `no-egress-test.sh` starts the embedded server with that
environment and uses the shared `builds/_shared/egress-verdict.sh` logic copied
into the rendered fork by `SHARED_FILES`; Linux's network namespace + strace is
authoritative, with a sandboxed macOS smoke.

## Security gates

Go `1.26.7` is the tag's toolchain; `1.26.9` is the same-minor stdlib security
override. No Go module override is applied. Headlamp cannot inherit the shared
Go setup/audit without a shared change: its module is `backend/go.mod`, while
the shared Go kind currently gates only `src/go.mod`, and its OCI image needs a
job after both the binary matrix and audit. This declaration therefore remains
`KIND=custom` and the workflow fails on every reachable govulncheck finding;
`vuln-ignore` is empty.

Status: **blocked on upstream** for `GO-2026-5064`, `GO-2026-5338`,
`GO-2026-5622`, and `GO-2026-5932`. With the vulnerability DB dated
2026-10-08, all four are reachable through init paths and have no fixed module
release. CI intentionally refuses to sign until upstream fixes them; none is
waived. The same four IDs are recorded in the rendered PIN as
`BLOCKED_ON_UPSTREAM`.

The frontend build applies four exact security-only dependency overrides
(`js-yaml`, `browserslist`, `fast-uri`, `source-map-js`) before the frozen
install. The frontend audit retains the complete JSON report. High/critical findings
fail unless the package is in the reviewed build-only set in
`npm-audit-gate.mjs`. At this tag the remaining audit findings are confined to
Vite/static-copy/lint globbing and unused crypto-polyfill dependencies;
`vite.config.ts` includes only `process`, `buffer`, and `stream`, not crypto.
Any new high/critical package fails closed.

`fork/` is generated by `../render.sh headlamp`; do not edit it directly. No
fork, tag, package, or outpost/yoke setting is changed by this repository work.
